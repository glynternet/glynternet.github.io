Draw mode

Use the rectangle/polygon tools on the map. New shapes use the selected mode. Exclude drops POIs inside it. If any Include area exists, only POIs inside an include area are kept (minus excludes).

The corridor is the band used by any tag filter with a distance. A solid band is a ≤ filter (it matches inside); a hatched one is a > filter (it matches outside).

    Load a route GPX to filter by distance from it.

      No tag filters. Load POIs to choose tags.

      Exclude drops POIs whose tags match. If any Include filter exists, only POIs matching an include filter are kept. Tag filters apply on top of (AND with) the area filters. Click a filter's chip to flip its mode.

      A distance narrows a filter to POIs ≤ (within) or > (beyond) that far from the route — so include ford=yes ≤50 m keeps only the fords you'd ride through, and exclude ford=yes >50 m keeps everything except the fords too far away. Leave it blank for no distance limit.
